## Le projet

Living Crops est une idée de projet personnel : un concept de mod Minecraft qui rend les cultures plus vivantes et évolutives.

## Autour du projet

Il s'inscrit dans mon intérêt pour le développement et la modification de Minecraft :

- mods Minecraft avec NeoForge ;
- configuration de serveurs ;
- création de concepts de mods et game design ;
- création d'éléments 3D avec Blockbench.
